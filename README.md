# 🎓 AI Study Buddy - Kenya

An AI-powered study assistant built with Python for Kenyan students.

## ✨ Features
- 📚 Answers study questions (KCSE, University)
- 📝 Summarizes long notes into key points
- ❓ Creates practice quizzes automatically
- 🇰🇪 Supports English + Swahili explanations

## 🧠 Tech Stack
- Python 3
- AI / Machine Learning
- Natural Language Processing

## 🚀 How to Run
```bash
python main.py
